# 🔐 QR Login Manager — одноразовые токены для безопасного входа

> «Отсканируй QR — войди без пароля»

**QR Login Manager** — это набор консольных утилит для генерации одноразовых QR-кодов, используемых для аутентификации.  
Каждый токен имеет ограниченный срок действия и может быть использован только один раз — идеально для двухфакторной аутентификации или входа без пароля.

## 🚀 Особенности
- 🎟️ Генерация одноразового токена (UUID v4).
- ⏳ Установка срока действия токена (по умолчанию 60 секунд).
- 📷 Создание QR-кода в формате PNG и/или ASCII-арт в терминале.
- 💾 Сохранение токена в JSON-файл вместе с меткой времени и TTL.
- 🔍 Проверка валидности токена (по времени).
- 🖥️ Поддержка цветного вывода и прогресс-индикация (где реализовано).
- 🔄 Возможность генерировать несколько токенов за раз.

## 🛠️ Установка и запуск

Для каждого языка — минимальные зависимости.

| Язык       | Библиотека(и)                    | Команда запуска                         |
|------------|----------------------------------|-----------------------------------------|
| Python     | `qrcode[pil]`, `Pillow`          | `python qr_login_manager.py`            |
| Go         | `github.com/skip2/go-qrcode`     | `go run qr_login_manager.go`            |
| JavaScript | `qrcode`, `uuid` (npm)           | `node qr_login_manager.js`              |
| Java       | `com.google.zxing:core`          | `javac -cp .:zxing.jar ... && java ...` |
| C#         | `QRCoder`, `System.Text.Json`    | `dotnet run`                            |
| Rust       | `qrcode`, `uuid`, `chrono`       | `cargo run`                             |
| Ruby       | `rqrcode`, `securerandom`        | `ruby qr_login_manager.rb`              |
| PHP        | `phpqrcode` (или `endroid/qr-code`) | `php qr_login_manager.php`          |

> По умолчанию токен сохраняется в `token.json`, QR-код — в `qrcode.png`, а в терминал выводится ASCII-представление.
